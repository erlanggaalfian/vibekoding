# vibekoding

Koleksi kebutuhan "vibe coding": design system, skill, dan contoh kode yang bisa dipakai ulang di proyek web.

## Isi

| Path | Keterangan |
|---|---|
| `design-system.md` | **Acuan desain utama.** Sistem desain NetBackup: tokens (warna, tipografi, shadow, motion), pola interaksi mobile app-like (collapsed-first accordion, bottom-sheet dialog, filter lipat), dan komponen. Kirim file ini saja saat ingin menerapkan gaya yang sama ke proyek lain. |
| `skills/netbackup-design-system/` | Skill untuk Muse: cara menerapkan design system ini ke proyek web apa pun (tokens → kontrak JS → pola per halaman → verifikasi). |
| `examples/demo.html` | Contoh mandiri (satu file, tanpa dependency): accordion per-item, filter collapsible, bottom-sheet `mConfirm`, badge, tombol, pagination, judul ketuk. Buka di browser; kecilkan ke ≤768px untuk melihat perilaku mobile. |

## Cara pakai

1. **Mau desain seperti ini di proyek baru?** Kirim `design-system.md` ke chat.
2. **Mau Muse yang menerapkan?** Skill `netbackup-design-system` sudah mengajarkan polanya.
3. **Mau lihat contoh hidup?** Buka `examples/demo.html`.
